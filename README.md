# Dad Joke Showdown

Entry for the make.fun competition `u-mfnakmal-dad-joke-showdown-1d2ce3e5`.

## What it does

`main.py` writes one dad joke to `/output/entry.txt`:

> I told my wife she should embrace her mistakes. She gave me a hug.

The joke is fixed and deterministic — the same text is written on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Why this joke

- It is a dad joke a father would tell at the table, in the first person.
- The pun lands on the first read: "embrace" as accept vs. "embrace" as a hug.
- The twist is fresh — the self-help cliche taken literally — while staying
  inside the dad joke tradition.
- It is tight (66 characters) with the punchline at the end, and reads
  naturally aloud.
